# Uzair Mukhtar - Data Analyst Portfolio

A lightweight, responsive portfolio for Uzair Mukhtar, built with semantic HTML, custom CSS, and vanilla JavaScript.

## Features

- CV-backed experience, projects, certifications, and contact details
- Responsive layouts for mobile, tablet, and desktop
- Remembered light and dark themes
- Accessible navigation, focus states, landmarks, and reduced-motion support
- Search and social metadata, structured data, sitemap, robots file, and favicon
- No framework, build step, or runtime dependency

## Local preview

Serve the repository root with any static file server, then open the local URL in a browser.

## Deployment

GitHub Pages publishes the root of the `main` branch to [uzair176.github.io](https://uzair176.github.io/).

## Updating content

See [MAINTENANCE.md](MAINTENANCE.md) for copy-ready patterns to add projects, certifications, skills, experience, and updated resume files without changing the design system.
